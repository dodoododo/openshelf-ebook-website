# A Quiet Place to Read

`sample.pdf` contains original development text and layout created for OpenShelf.
To the extent any copyright or related rights exist, the authors dedicate this
sample's text and layout to the public domain under **CC0 1.0 Universal**:
https://creativecommons.org/publicdomain/zero/1.0/

You may copy, modify, and redistribute this fixture, including commercially,
without permission or attribution. It contains no private uploaded content,
downloaded book excerpts, images, or embedded third-party fonts. The PDF references
the standard PDF Times-Roman and Helvetica fonts.

Rebuild from the repository root with `python scripts/create-sample-pdf.py`
(requires Python and `reportlab`). The source uses deterministic PDF metadata.
Five pages deliberately exercise a final unpaired page in double-page mode.

The sample is a public static development asset, even though the Reader route
requires a live session. It must not be used as a model for private PDF delivery.
